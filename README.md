# ЛЮКС-7 — Рогалик-Казино · v2.1

Одностраничная браузерная игра: рогалик, построенный на азартных играх.

**Один файл. Никаких зависимостей. Работает офлайн.**

## Что нового в v2.1

- **Забег заканчивается при фишках < 10.** Как только на счету меньше минимальной ставки — экран разорения, а не бесконечное закрытие вкладки.
- **Система достижений** — 14 ачивок с анимацией всплытия и конфетти при разблокировке.
- **Топ-5 рекордов** — все забеги сохраняются в localStorage, отдельный экран со статистикой и кнопкой очистки.
- **Серии побед** — 3 победы подряд дают +15% ко всем выплатам (бейдж 🔥 рядом с балансом). Проигрыш сбрасывает.
- **Случайные события на лифте** — 25% шанс получить +20…120 фишек за подъём.
- **Горячие клавиши (ПК)** — 1-5 столов, Space основное действие, Esc назад, R/A рекорды и ачивки, M звук, H помощь.
- **Low-money UI** — предупреждение «последний шанс» появляется на балансе < 30, баланс мигает при < 10.

## Что было в v2.0

- **Десктоп-раскладка** от 900px: широкий «кабинет» с 3-колоночной сеткой.
- **Много анимаций**: частицы фона, конфетти, ripple по кнопкам, 3D-ховеры карт.
- **Кастомная SVG-фишка «7»** вместо ₽ (она же favicon).
- **Рулетка** (европейская, одно зеро).
- **Автосейв** забега, **звук** на Web Audio.

## Игровой цикл

1. Старт: 100 фишек, этаж 1.
2. Играешь в один из 5 столов → растёт или падает баланс.
3. Платишь за лифт → поднимаешься, получаешь **перк**, иногда — **случайное событие**.
4. Со 2-го этажа на каждом этаже шанс **проклятия** (58%), которое меняет правила.
5. Этаж 10 — выход. Забираешь деньги домой.
6. **Фишки < 10 → забег закончен.**

## Адаптивность

- **Мобильный (до 900px):** вертикальный поток, sticky bottom bar.
- **Десктоп (900–1200px):** 1080px, 3 колонки столов, увеличенные сцены, клавиатурные подсказки.
- **Широкий (1200px+):** до 1180px.

Анимации отключаются при `prefers-reduced-motion`. Hover не работает на тачах (`@media (hover: none)`).

## Технические детали

- Ванильный JS, без сборки.
- Canvas-фоны: `#stars`, `#confetti`.
- Звук — Web Audio API (осцилляторы).
- Состояние — в памяти, между забегами сохраняются рекорд, текущий забег и ачивки.
- Ключи localStorage: `lux7_best_v1`, `lux7_run_v1`, `lux7_ach_v1`, `lux7_rec_v1`, `lux7_sound`.

## Баланс (для настройки)

Константы в начале `<script>`:

- `MIN_BET` — порог финала (по умолчанию 10)
- `STREAK_BONUS` / `STREAK_MIN` — бонус за серию
- `PERKS`, `CURSES` — перки и проклятия
- `LIFT_EVENTS` — события лифта
- `SLOT_SYMBOLS` — барабаны
- `anteCost()` — формула цены лифта
- `BET_STEPS` — лестница ставок
- `ACHIEVEMENTS` — список ачивок

## Кастомизация монеты

Иконка в `chipCoinSVG()` — SVG-строка. Favicon в `<head>` — та же картинка в data-URI. Меняй цвет в `<radialGradient>` и цифру в `<text>7</text>`.
