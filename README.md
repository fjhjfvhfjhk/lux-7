# ЛЮКС-7 — Рогалик-Казино · v2.4

Рогалик, построенный на азартных играх. Статический сайт, работает офлайн, ставится как PWA.

## Структура файлов

```

index.html     — HTML-оболочка + SVG-спрайт иконок
styles.css     — все стили (~40 КБ)
app.js         — вся логика (~45 КБ)
manifest.json  — PWA-манифест
icon.svg       — иконка приложения
README.md      — этот файл

```

**Почему три файла, а не один.** Игра разрослась до ~140 КБ исходника. В одном файле я упирался в лимит вывода и резал контент. Плюс: браузер кэширует CSS и JS отдельно, правки в логике не перезагружают стили, а размер каждого файла комфортно читается человеком.

## Как запустить

### Локально
```bash
python3 -m http.server 8000
# http://localhost:8000
```

Или просто открой `index.html` — CSS и JS подхватятся через относительные пути.

### Публикация

GitHub Pages / Netlify / Vercel — все 6 файлов должны лежать в одной директории.

## Игровой цикл

1. **Выбор класса** — Считающий / Фортуна / Рисковый.
2. Старт: 100 фишек, этаж 1.
3. Играешь в один из 5 столов.
4. Лифт → **перк** → **магазин** → следующий этаж.
5. На **3, 6, 9** этажах — боссы с правилом и наградой.
6. Этаж 10 → выход.
7. **Фишки < мин. ставки → забег закончен.**

## Архитектура кода

**`index.html`** содержит только:

- `<head>` со метаданными, favicon и `<link>` на CSS
- SVG-спрайт с 51 `<symbol>` (один раз, inline)
- Пустые контейнеры: `#app`, `#toasts`, `#modal-root`, `<canvas>`
- `<script src="app.js">`

**`styles.css`** — вся визуальная часть:

- CSS-переменные для тем (`--panel`, `--gold`, ...)
- Три этажных темы через `body[data-theme]`
- Пять игровых тем через `body[data-game]`
- Анимации, ripple, все компоненты

**`app.js`** — вся логика:

1. Утилиты (`$`, `ico()`, `fmt()`, `sleep()`)
2. Звук и музыка (Web Audio, без файлов)
3. Константы (`PERKS`, `CURSES`, `CLASSES`, `BOSSES`, `SHOP_ITEMS`)
4. Состояние `S` + localStorage
5. Темы: `applyTheme()`, `setGameTheme()`
6. Модификаторы: `modMult()`, `bossMods()`, `classMods()`
7. Ставки: `betSteps()`, `syncBetUI()`, `quickBet()`
8. Рендер: `render()` и его кейсы
9. Игры: `spin()`, `rollDice()`, `guessHL()`, `bjDeal()`, `spinRoulette()`
10. Экраны: `hubScreen()`, `classScreen()`, `shopScreen()`, `achScreen()`, `recordsScreen()`
11. Модалки: `showHelp()`, `showBossIntro()`, `showBossInfo()`
12. Финалы: `endRun()`, `renderEnd()`, `shareResult()`
13. Фон и конфетти (IIFE)
14. Хоткеи и бут

### Экспорт в глобальный скоуп

Поскольку `app.js` подключён как `<script src>`, все функции и `S` **не видны** в `onclick="..."` атрибутах по умолчанию. В конце файла есть блок:

```
Object.assign(window, {
  go, goHub, takeElevator, choosePerk, /* ... */
});
```

Если добавляешь новую функцию, вызываемую из inline-обработчика, обязательно добавь её в этот объект.

## Игровые темы (для кастомных)

Добавь в `styles.css`:

```
body[data-game="mytheme"] {
  --panel:#xxx; --panel2:#xxx; --panel3:#xxx;
  --line:#xxx; --line2:#xxx;
}
```

И вызывай `setGameTheme('mytheme')` при входе в соответствующий стол.

## Боссы (для кастомных)

Добавь в `BOSSES` объект:

```
BOSSES[5] = {
  id:'myboss', icon:'b-keeper', name:'Имя',
  quote:'«...»', desc:'Правило',
  mods: { winTax: 0.1 },   // любые: slotsPay, bjBonus, minBet, maxBet, winTax
  rewardChips: 500,
  rewardText: '+500 фишек',
};
```

`mods` автоматически применяются через `bossMods()` в `modMult()`, `minBetNow()`, `maxBet()`, `payout()`. Ачивки за победу добавляются отдельно в `grantBossReward()`.

## Roadmap

**Атмосфера**

- Отдельная музыкальная тема для боссов.
- Пульс фона в красных тонах при проклятиях.
- Отдельные фоновые текстуры под каждую игровую тему.

**Механики**

- Ежедневный забег с общим seed.
- Гача-машина: скины рубашки за общее число фишек.
- Активные способности: подсмотреть карту, заморозить проклятие.
- Второй этап босса при прохождении «идеально».

**Прогрессия**

- Разблокировка классов за ачивки.
- Престиж после выхода с 10-го этажа.
- Мета-валюта за ачивки.

**Эксплуатация**

- Service Worker для настоящего оффлайна.
- Аналитика на localStorage: какие перки берут, где умирают чаще.
