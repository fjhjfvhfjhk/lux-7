# ЛЮКС-7 — Рогалик-Казино · v2.2

Одностраничная браузерная игра: рогалик, построенный на азартных играх.

**Один index.html. Никаких зависимостей. Работает офлайн. PWA.**

## Что нового в v2.2

- **🐛 Исправлен критический баг навигации.** Клик по «Достижения» с экрана смерти и потом «Назад» больше не возвращает в игру с 0 фишек — вы возвращаетесь на экран результата.
- **🎓 Классы персонажа** — в начале забега выбор из трёх: Считающий, Фортуна, Рисковый. Каждый меняет правила.
- **🛒 Магазин между этажами** — тратить фишки: снять проклятие (200), случайный перк (400), оберег на след. этаж (80), страховка +40 фишек (30).
- **🎨 Темы этажей** — 1–3 тёплый коричневый, 4–6 багровый, 7–9 ледяной синий, 10 королевский фиолетовый.
- **🎵 Амбиентная музыка** — три медленных синуса с LFO, отдельный тумблер (Web Audio, не требует аудиофайлов).
- **📋 Кнопка «Поделиться»** — на экране смерти копирует результат в буфер или открывает системный шар-шит на мобиле.
- **✍️ Имена в рекордах** — при новом личном рекорде просит ввести имя, отображается в топ-5.
- **📱 PWA-манифест** — можно установить на домашний экран как приложение.

## Что было раньше

**v2.1**: финал при <10 фишек, ачивки, топ-5 рекордов, серии побед (+15% с 3 подряд), события лифта, горячие клавиши, low-money UI.

## Как запустить

### Вариант 1 — просто открыть
Скачай `index.html`, открой в браузере. Всё.

### Вариант 2 — локальный сервер (для PWA)
```bash
python3 -m http.server 8000
# http://localhost:8000
```

### Вариант 3 — публикация

Статика. Кидай папку на GitHub Pages, Netlify, Vercel. Все три файла (`index.html`, `manifest.json`, `icon.svg`) должны быть в одной директории.

## Файлы

```
index.html     — вся игра (HTML + CSS + JS в одном файле)
manifest.json  — PWA-манифест
icon.svg       — иконка приложения / favicon
README.md      — этот файл
```

## Игровой цикл

1. **Выбор класса** — Считающий / Фортуна / Рисковый.
2. Старт: 100 фишек, этаж 1.
3. Играешь в один из 5 столов.
4. Платишь за лифт → **перк** → **магазин** → следующий этаж.
5. Иногда проклятия, иногда — бонусы от лифта.
6. Этаж 10 → выход.
7. **Фишки < 10 → забег закончен.**

## Адаптивность

- **Мобильный (до 900px):** вертикальный поток, sticky bottom bar.
- **Десктоп (900–1200px):** 1080px, 3 колонки столов, увеличенные сцены, клавиатурные подсказки.
- **Широкий (1200px+):** до 1180px.

Анимации отключаются при `prefers-reduced-motion`.

## Технические детали

- Ванильный JS, без сборки.
- Canvas-фоны: `#stars` и `#confetti`.
- Звук и музыка — Web Audio API (осцилляторы + LFO), без сэмплов.
- PWA без service worker (кэширование не требуется — всё в одном файле).

### Ключи localStorage

- `lux7_best_v1` — личный рекорд
- `lux7_run_v1` — текущий забег (автосейв в хабе)
- `lux7_ach_v1` — открытые ачивки
- `lux7_rec_v1` — топ-5 забегов
- `lux7_name_v1` — имя игрока
- `lux7_sound` — вкл/выкл звук
- `lux7_music` — вкл/выкл музыку

## Настройка баланса

Константы в начале `<script>`:

- `MIN_BET` — порог финала (по умолчанию 10)
- `STREAK_BONUS` / `STREAK_MIN` — бонус за серию
- `CLASSES` — классы персонажа
- `SHOP_ITEMS` — товары магазина
- `PERKS` / `CURSES` — перки и проклятия
- `LIFT_EVENTS` — события лифта
- `BET_STEPS` — лестница ставок
- `SLOT_SYMBOLS` — барабаны
- `anteCost()` — формула цены лифта

## Кастомизация монеты

Иконка в `chipCoinSVG()` — SVG-строка. Favicon в `<head>` — та же картинка в data-URI. Большая иконка в `icon.svg`. Меняй цвет в `<radialGradient>` и цифру в `<text>7</text>` — везде должно быть одинаково.
