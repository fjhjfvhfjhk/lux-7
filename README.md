# ЛЮКС-7 — Рогалик-Казино · v2.3

Одностраничная браузерная игра: рогалик, построенный на азартных играх.

**Один index.html. Никаких зависимостей. Работает офлайн. PWA.**

## Что нового в v2.3

- **🎨 Кастомный SVG-иконсет вместо эмодзи.** 48 иконок в едином стиле: 24×24 viewBox, обводка 1.65px, круглые концы, `stroke: currentColor` — автоматически принимают цвет окружения (золото, красный, синий).
- **Спрайт одной вставкой.** Все иконки — `<symbol>` внутри одного скрытого `<svg>` в начале `<body>`. Никаких внешних файлов, никаких HTTP-запросов.
- **Хелпер `ico(name, size)`.** Одна функция возвращает готовую SVG-разметку. Простое и предсказуемое использование: `ico('g-bj', 40)`.
- **Убраны эмодзи из текстов** — тосты теперь используют SVG-иконки или просто текст с цветовой кодировкой.
- **Цветные SVG-символы слотов.** Барабаны теперь рисуются как настоящие плоды/предметы: вишня, лимон, колокольчик, алмаз, семёрка, череп — цветной SVG вместо эмодзи.

## Как запустить

### Вариант 1 — просто открыть
Скачай папку, открой `index.html` в браузере. Всё.

### Вариант 2 — локальный сервер (для PWA)
```bash
python3 -m http.server 8000
# http://localhost:8000
```

### Вариант 3 — публикация

Статика. Кидай папку на GitHub Pages, Netlify, Vercel.

## Иконсет

Все иконки определены как `<symbol>` в SVG-спрайте в начале `<body>`:

| Префикс ↕▾ | Назначение ↕▾ | Кол-во ↕▾ |
|---|---|---|
| −`g-` | Игры (блэкджек, рулетка, кости, хай-лоу, слоты) | 5 |
| −`p-` | Перки (огонь, мозг, читерские кости, щит, туз, кит, клевер, ключ) | 8 |
| −`c-` | Проклятия (туман, налог, кровь, череп, лёд, сухость) | 6 |
| −`k-` | Классы (градуационная шапка) | 1 |
| −`s-` | Магазин (ножницы, подарок, амулет, сердце) | 4 |
| −`a-` | Достижения (галочка, монеты, 777, красное, зеро, лифт, корона, дверь, кошелёк) | 9 |
| −`u-` | UI (назад, помощь, звук, музыка, share, замок, стрелка) | 7 |
⚙

Использование в JS:

```
ico('g-bj', 40)   // большая иконка блэкджека на 40px
ico('p-hot', 14)  // маленький огонёк серии в бейдже
```

Цвет наследуется через CSS `color` родителя. Например, в `.gcard` иконка золотая, в `.badge.curse` — красная, в `.badge.cls` — синяя.

## Игровой цикл

1. **Выбор класса** — Считающий / Фортуна / Рисковый.
2. Старт: 100 фишек, этаж 1.
3. Играешь в один из 5 столов.
4. Платишь за лифт → **перк** → **магазин** → следующий этаж.
5. Иногда проклятия, иногда — бонусы от лифта.
6. Этаж 10 → выход.
7. **Фишки < 10 → забег закончен.**

## Адаптивность

- **Мобильный (до 900px):** вертикальный поток, sticky bottom bar, компактные иконки.
- **Десктоп (900–1200px):** 1080px, 3 колонки столов, крупные SVG-иконки (52px у столов, 96px на экране итогов).
- **Широкий (1200px+):** до 1180px.

Анимации отключаются при `prefers-reduced-motion`.

## Технические детали

- Ванильный JS, без сборки.
- Canvas-фоны: `#stars` и `#confetti`.
- Звук и музыка — Web Audio API.
- SVG-спрайт — 48 иконок, ~5 КБ.
- PWA без service worker (всё в одном файле).

### Ключи localStorage

- `lux7_best_v1` — личный рекорд
- `lux7_run_v1` — текущий забег (автосейв в хабе)
- `lux7_ach_v1` — открытые ачивки
- `lux7_rec_v1` — топ-5 забегов
- `lux7_name_v1` — имя игрока
- `lux7_sound` — вкл/выкл звук
- `lux7_music` — вкл/выкл музыку

## Настройка

Константы в начале `<script>`:

- `MIN_BET` — порог финала
- `STREAK_BONUS` / `STREAK_MIN` — бонус за серию
- `CLASSES`, `SHOP_ITEMS`, `PERKS`, `CURSES`, `LIFT_EVENTS`, `ACHIEVEMENTS`
- `BET_STEPS`, `SLOT_SYMBOLS`
- `anteCost()` — формула цены лифта

## Как добавить свою иконку

1. Добавь `<symbol id="my-icon" viewBox="0 0 24 24">...</symbol>` в спрайт.
2. Используй `ico('my-icon', 24)` где нужно.
3. Стиль автоматически подхватится (stroke: currentColor, 1.65px, round caps).

## Roadmap / Идеи на будущее

**Атмосфера**

- Плавные переходы между экранами (View Transitions API, если поддерживается).
- Отдельные звуковые лупы для каждого этажа (низкие/высокие тона).
- Реакция фона на события: при крупном выигрыше частицы начинают пульсировать.
- Отдельные CSS-темы для каждой игры (стол БД — зелёный фетр, слоты — неон).

**Механики**

- **Ежедневный забег** с общим seed и локальным лидербордом «сегодня».
- **Боссы на 3/6/9 этажах** — форс-мажор с изменёнными правилами.
- **Гача-машина** между забегами: за общее число фишек открывать скины рубашки карт.
- **Кастомные правила в магазине**: «запретить чёрное на следующий спин», «форс-проигрыш на 5-й ставке».
- **Кража фишек** в редком событии — либо отдай 15%, либо рискни вслепую.
- **Активные способности**: раз в 3 этажа «подсмотреть следующую карту» или «заморозить проклятие на 1 ход».

**Прогрессия**

- **Разблокировка классов** за ачивки (например, «Считающий» открывается после 5 побед в БД).
- **Престиж**: после выхода с 10 этажа можно начать новый забег с бонусом +1 к лифтовому бюджету.
- **Мета-валюта** (жетоны) за каждую ачивку, тратится на косметические скины рубашки и звуковые пакеты.

**Социальное**

- Ссылка-челлендж с seed: `?challenge=xxxxx` — один и тот же забег для всех.
- Экспорт/импорт сохранения через base64-строку — перенос прогресса между устройствами.

**Эксплуатация**

- Service Worker для настоящего оффлайна и установки как PWA.
- Web Share Target: получать challenge-ссылки из системного «Поделиться».
- Аналитика на localStorage: сколько средних забегов до выхода, какие перки чаще берут.
